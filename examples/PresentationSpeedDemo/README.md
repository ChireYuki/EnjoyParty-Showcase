# 演出倍速投票：独立代码样例

`PvePresentationSpeedVote.cs` 来自完整项目的同名纯 C# 文件。本目录不需要 Unity、原作素材或联网账户。

## 要解决的问题

玩家可能在移动、攻击或过场演出中提出倍速调整。立即改速会让一个动作前后使用不同的播放时钟，因此通过投票后先进入 `Scheduled`，直到下一玩家回合边界才正式生效。

示例分为两部分：

- `PvePresentationSpeedVote`：提案、全员同意、拒绝、超时、成员变化取消，以及延迟应用。
- `PvePresentationTimeline`：让演出时钟连续推进，不回算过去已经经过的时间。

这里的参与者掩码只用于说明四席逻辑。例如 `15` 的二进制为 `1111`，表示四席真人；`5` 为 `0101`，表示第 1、3 席真人。

## 可选：运行检查

只想阅读项目时，无须安装任何东西。

如果电脑已安装 **.NET 10 SDK**，在仓库根目录执行：

```text
dotnet run --project examples/PresentationSpeedDemo
```

检查程序会打印每个场景的结果；全部通过时退出码为 0，失败时为 1。程序不访问网络，不读写游戏档案，也不包含 NuGet 第三方包。`NuGet.Config` 清空此样例的包源，避免恢复阶段访问外部包服务。

## 范围限制

`Program.cs` 是为本展示仓库补充的小型检查器，不是完整游戏的 NUnit 测试套件。这个示例不包含真正的网络鉴权、RPC、UI、音效或移动动画。

真实游戏必须在网络边界验证请求来源；不能仅凭调用方传入的 `isHost` 参数判断其权限。
