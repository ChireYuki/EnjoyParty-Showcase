# EnjoyParty

一个使用 Unity 制作的非官方二创合作 PVE 棋盘游戏原型。

项目围绕掷骰移动、卡牌战斗和团队任务展开，目前包含「异变图书馆·审判庭」和「界园志异」两张地图。当前 Windows 展示版本为 **v1.1**。

本仓库用于展示玩法设计、开发过程和少量技术实现，不是完整游戏工程，不包含原作提取素材、联机凭据或游戏安装包，也不代表任何原作官方项目。

## 可以看到什么

- **审判庭玩法**：图书馆调查、阶段转换、魔女因子、残骸、任务证据，以及团队反驳流程。
- **棋盘与战斗**：路线预览、分岔选择、疾行与传送、卡牌商店、筹码，以及角色技能和怪物战斗。
- **联机与演出**：房主权威规则、状态快照、客户端演出队列，以及全员投票通过后在下一玩家回合切换的 1× / 2× / 5× 演出速度。
- **实际迭代**：从测试反馈修正界面隐藏、立绘取景、跨房间场景残留等问题。

## 当前进度

完整项目最近一次记录于 **2026-10-27**：1112 项 EditMode 自动化测试通过，0 失败、0 跳过；Windows x64 构建和启动检查通过。

审判庭退房后同图重开、设置菜单和两图切换已有本地 Host 验证。这些结果不等于公网多人、完整长局、所有分辨率或安卓已经验证。仓库中的独立样例也不包含完整项目的全部测试。

## 技术栈

Unity 2022.3.22f1 · C# · URP · uGUI · Netcode for GameObjects · Unity Transport / UOS Sync Relay 接入

联机目前仍处于测试阶段，不能将“已接入中转”理解为“已完成公网稳定性验收”。

## 关于这个项目

本人主要负责玩法构思、参考分析、规则需求、程序、操作测试与体验验收。部分程序、自动化测试和部分视觉制作使用 AI 辅助，具体分工见[职责说明](docs/Contributions.md)。

玩法与内容参考《吉星派对》《魔法少女的魔女审判》《明日方舟》等作品。
